安装机制逆向「点击召唤到底做了什么」

  1. 召唤 = 真安装。点击专家「召唤」会触发 ensureDownloaded() → 下载 tar.gz → 解压到 plugins/marketplaces/experts/plugins/<name>/ → 增量回写 marketplace.json 并留 .downloaded_at 时间戳。
  2. 公开回退源（本拆解的核心突破）。客户端逻辑里存在 explicitBundleUrl || 默认COS地址 双源降级；而默认地址指向一个无签名、可枚举的腾讯云 COS 桶，于是可以绕过 GUI 一键全量安装。
  3. 三类包：市场公开专家（COS 直下）、内置专家（随 app 分发）、19 位内部专家（走运营平台预签名 URL，本地无公开包，只能 GUI 召唤）。
① GUI 召唤
  • 人工逐一点击，单个安装
  • 完整权限链路
② CLI 安装
  • codebuddy plugin install <name>@experts
  • 只认本机 marketplace.json 已有条目
  • 清单缺条目时反而装不了（被误判为网络问题）
③ 批量脚本（本次采用）
  • 读远端 expert_center.json 拿 421 个 bundle 名
  • 并发 10 路下载 COS tar.gz → 解压 → 校验 → 原子落盘
  • 48 秒装完全部 421 个，0 失败
